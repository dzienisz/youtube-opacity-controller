# Chrome Web Store Listing Translations

Translations of the store listing from [CHROME_WEB_STORE_GUIDE.md](../CHROME_WEB_STORE_GUIDE.md).
In the Developer Dashboard: **Store listing → Add languages**, then paste the matching block.
Short descriptions are all under the 132-character limit. Languages match `_locales/` in the extension, so the name/short description shown in the store header will agree with what users see after install.

Dashboard language names: English, Portuguese (Brazil), Spanish (Latin America), German, Japanese, Korean, Arabic, Ukrainian, Vietnamese, Hindi, Polish, French, Italian, Russian, Chinese (Simplified).

## English — `en`

### Short Description

```text
Make YouTube controls easier to see, click, and keep visible.
```

### Detailed Description

```text
Make YouTube player controls easier to see and use without changing your whole browser or operating system.

YouTube Controls: Clearer & Larger improves the existing player interface on bright and visually busy videos. Choose a ready-made control style, keep controls visible when needed, or customize the background strength.

FEATURES

• Clear Controls style with an adjustable dark control background
• Strong Contrast style for stronger, clearer controls
• Bigger progress bar with a larger, easier-to-grab handle
• Highlight colors for the progress bar, handle, icons, and time
• Easier-to-read subtitles: larger subtitles on a solid dark background (applies only when you turn captions on in a video)
• Restore YouTube's look: one click turns every change off and keeps your choices for later
• Keyboard shortcuts with an on-player confirmation, rebindable at chrome://extensions/shortcuts
• Larger mouse pointer over the video
• Optional Keep Controls Visible setting
• Instant preview and settings synchronized through Chrome
• Master switch to return to the original YouTube appearance
• Lightweight CSS-only visual changes

SAFE BY DESIGN

• Does not move, clone, or replace YouTube controls — adds only one small on-player status overlay
• Runs only on youtube.com, including embedded players
• No account, analytics, tracking, advertisements, or external requests
• Open source at github.com/dzienisz/youtube-opacity-controller

HOW TO USE

1. Open a YouTube video.
2. Select the extension icon.
3. Choose Clear Controls or Strong Contrast.
4. New installs start with recommended settings; use "Use recommended settings" in the popup to apply them any time.
5. Optionally keep controls visible, enlarge the progress bar or pointer, pick a highlight color, or customize the background.
6. Press Alt+Shift+Y to toggle enhancements, Alt+Shift+J to cycle styles, Alt+Shift+V to toggle keep-controls-visible.
7. Use the "Restore YouTube's look" button or master switch at any time to turn every change off; your choices are kept for later.

Designed for viewers who find transparent controls difficult to locate, read, or operate on bright and busy video content.
```


### Detailed Description

```text
Mach die YouTube-Player-Steuerung leichter sichtbar und bedienbar, ohne den ganzen Browser oder das Betriebssystem umzustellen.

YouTube-Steuerung: Klarer & Größer verbessert die vorhandene Player-Oberfläche bei hellen und visuell unruhigen Videos. Wähle einen fertigen Steuerungsstil, halte die Steuerelemente bei Bedarf sichtbar oder passe die Hintergrundstärke an.

• YouTube-Ansicht wiederherstellen: Ein Klick schaltet alle Änderungen aus und behält deine Einstellungen für später bei
• Tastenkürzel mit Bestätigung im Player, anpassbar unter chrome://extensions/shortcuts
• Größerer Mauszeiger über dem Video
• Optionale Einstellung „Steuerelemente sichtbar halten“
• Sofortige Vorschau und über Chrome synchronisierte Einstellungen
• Hauptschalter, um zur ursprünglichen YouTube-Darstellung zurückzukehren
• Leichtgewichtige, rein CSS-basierte visuelle Änderungen

SICHER KONZIPIERT

• Verschiebt, dupliziert oder ersetzt keine YouTube-Steuerelemente — fügt nur eine kleine Statusanzeige im Player hinzu
• Läuft ausschließlich auf youtube.com, einschließlich eingebetteter Player
• Kein Konto, keine Analysen, kein Tracking, keine Werbung, keine externen Anfragen
• Open Source auf github.com/dzienisz/youtube-opacity-controller

SO GEHT'S

1. Öffne ein YouTube-Video.
2. Klicke auf das Symbol der Erweiterung.
3. Wähle „Klare Steuerung“ oder „Starker Kontrast“.
4. Neue Installationen starten mit den empfohlenen Einstellungen; nutze „Empfohlene Einstellungen verwenden“ im Pop-up, um sie jederzeit anzuwenden.
5. Halte optional die Steuerelemente sichtbar, vergrößere Fortschrittsleiste oder Zeiger, wähle eine Hervorhebungsfarbe oder passe den Hintergrund an.
6. Drücke Alt+Shift+Y, um die Verbesserungen umzuschalten, Alt+Shift+J, um den Stil zu wechseln, Alt+Shift+V, um „sichtbar halten“ umzuschalten.
7. Verwende jederzeit die Schaltfläche „YouTube-Ansicht wiederherstellen“ oder den Hauptschalter, um alle Änderungen auszuschalten; deine Einstellungen bleiben für später erhalten.

Entwickelt für alle, denen transparente Steuerelemente auf hellen und unruhigen Videos schwer zu finden, zu lesen oder zu bedienen sind.
```

## Japanese — `ja`

### Short Description

```text
YouTube の操作ボタンを見やすく、押しやすく、常に表示できるようにします。
```

### Detailed Description

```text
ブラウザや OS 全体の設定を変えることなく、YouTube プレーヤーの操作ボタンを見やすく、使いやすくします。

YouTube コントロール: より見やすく、より大きく は、明るい映像や視覚的に情報量の多い映像でも、既存のプレーヤー UI を見やすく改善します。用意されたコントロールのスタイルを選ぶだけでも、コントロールを常に表示したままにしたり、背景の濃さを細かく調整したりすることもできます。

機能

• 調整可能な暗い背景を備えた「クリアなコントロール」スタイル
• より濃く、はっきりしたコントロールの「強いコントラスト」スタイル
• つかみやすい大きなハンドル付きの大きなプログレスバー
• プログレスバー、ハンドル、アイコン、時間表示に適用できるハイライトカラー
• 読みやすい字幕：暗い単色の背景に大きな字幕を表示（動画で字幕をオンにした場合のみ適用）
• YouTubeの元の表示に戻す：ワンクリックですべての変更をオフにし、設定は後から使えるよう保存
• プレーヤー上で確認表示が出るキーボードショートカット（chrome://extensions/shortcuts で変更可能）
• 動画上で大きくなるマウスポインター
• コントロールを表示したままにするオプション
• 即時プレビューと Chrome 経由での設定同期
• ワンタッチで元の YouTube の外観に戻せるマスタースイッチ
• CSS のみの軽量な見た目の変更

安全設計

• YouTube のコントロールを移動・複製・置き換えしません — 小さなステータス表示をプレーヤー上に追加するだけです
• 埋め込みプレーヤーを含め、youtube.com 上でのみ動作します
• アカウント不要。分析・トラッキング・広告・外部通信は一切ありません
• オープンソース：github.com/dzienisz/youtube-opacity-controller

使い方

1. YouTube の動画を開きます。
2. 拡張機能のアイコンをクリックします。
3. 「クリアなコントロール」または「強いコントラスト」を選択します。
4. 新規インストールではおすすめ設定が適用されます。ポップアップの「おすすめ設定を使う」で、いつでも適用できます。
5. 必要に応じて、コントロールの常時表示、プログレスバーやポインターの拡大、ハイライトカラーの選択、背景の調整を行います。
6. Alt+Shift+Y で拡張表示の切り替え、Alt+Shift+J でスタイルの切り替え、Alt+Shift+V で常時表示の切り替えができます。
7. 「YouTubeの元の表示に戻す」ボタンまたはマスタースイッチを使うと、いつでもすべての変更をオフにでき、設定は後から使えるよう保存されます。

明るく情報量の多い映像で、透明なコントロールが見つけにくい・読みにくい・操作しにくいと感じる方のために設計されています。
```

### Short Description

```text
브라우저나 운영체제 전체 설정을 바꾸지 않고도 YouTube 플레이어 컨트롤을 더 잘 보이고 사용하기 쉽게 만드세요.

YouTube 컨트롤: 더 선명하고 크게는 밝거나 시각적으로 복잡한 영상에서 기존 플레이어 인터페이스를 개선합니다. 미리 준비된 컨트롤 스타일을 선택하고, 필요할 때 컨트롤을 계속 표시하거나 배경 강도를 직접 조절할 수 있습니다.

기능

• 조절 가능한 어두운 컨트롤 배경을 제공하는 선명한 컨트롤 스타일
• 더 진하고 선명한 컨트롤을 위한 강한 대비 스타일

• 더 읽기 쉬운 자막: 어두운 단색 배경에 더 큰 자막 표시 (동영상에서 자막을 켠 경우에만 적용)
• YouTube 원래 모습 복원: 한 번 클릭하면 모든 변경 사항을 끄고 설정은 나중에 사용할 수 있도록 저장
• 플레이어에서 확인 표시가 나타나는 키보드 단축키(chrome://extensions/shortcuts에서 변경 가능)
• 동영상 위에서 더 커지는 마우스 포인터
• 컨트롤 계속 표시 옵션
• 즉시 미리보기 및 Chrome을 통한 설정 동기화
• 원래 YouTube 모습으로 되돌리는 마스터 스위치
• CSS만 사용하는 가벼운 시각적 변경

안전한 설계

• YouTube 컨트롤을 이동, 복제, 대체하지 않습니다 — 플레이어에 작은 상태 표시 하나만 추가합니다
• 임베디드 플레이어를 포함해 youtube.com에서만 실행됩니다
• 계정, 분석, 추적, 광고, 외부 요청이 전혀 없습니다
• 오픈 소스: github.com/dzienisz/youtube-opacity-controller

사용 방법

1. YouTube 동영상을 엽니다.
2. 확장 프로그램 아이콘을 클릭합니다.
3. 선명한 컨트롤 또는 강한 대비를 선택합니다.
4. 새로 설치하면 권장 설정이 적용됩니다. 팝업에서 "권장 설정 사용"을 선택해 언제든 적용하세요.
5. 필요하면 컨트롤을 계속 표시하고, 진행 바나 포인터를 키우고, 강조 색상을 고르거나 배경을 조절합니다.
6. Alt+Shift+Y로 개선 기능을, Alt+Shift+J로 스타일을, Alt+Shift+V로 계속 표시를 전환합니다.
7. 언제든지 "YouTube 원래 모습 복원" 버튼이나 마스터 스위치를 사용해 모든 변경 사항을 끄고 설정을 나중에도 사용할 수 있도록 보존하세요.

밝고 복잡한 영상에서 투명한 컨트롤을 찾거나 읽거나 조작하기 어려운 시청자를 위해 설계되었습니다.
```
